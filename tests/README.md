# Orchestration tests

Run from anywhere on WSL:

```bash
bash run-tests.sh
```

It syncs this checkout's uv-managed environment (`envpath.py`) and runs every `test_*.py`. On Windows,
from this checkout in that host's environment, the files that exercise a host run the same way:
`uv run --locked python -m unittest tests.test_launch tests.test_terminal tests.test_repos tests.test_trust tests.test_worktrees tests.test_workflow tests.test_stops tests.test_replay tests.test_trace_parity`.

| file | proves |
|---|---|
| `test_workflow.py` | the workflow's contract on Temporal's time-skipping test server, over the fake seams: verdict routing over `PASS/PATCH/UNVERIFIED/BLOCKER`; the exact `max_rounds` boundary; malformed reviewer output and a broken stream stopping as failures, never as verdicts; a resumed stop re-running no agent; guidance re-entry resetting the round; session identity with exact-id resume and `--last` banned; the architect launched read-only; mid-loop session loss rehydrating completely for both roles; guidance reaching the architect; log names unique across episodes; policy validation, the D3 independent-judge rule and one queue per target host; Continue running only the failed stage; and an answer from another process continuing the run while an unknown run id is refused. Every workflow scenario fails against `empty_workflow.py` |
| `test_stops.py` | answers a stop does not offer are rejected before they reach history, and one answer sent twice is applied once — control: `control_workflows.NoValidatorRun`; a lost role activity launched once — control: `RetryControl` under Temporal's default retries; a role running only on its target host's queue — control: the queue, not the target, decides; a refused repository creating no worktree; and the final gate — merge, revise to the engineer or the architect, a discard that needs confirming, a conflict handed back to the engineer, a refused merge staying at the gate |
| `test_observability.py` | what the operator observes: console lines, `--show`, the preflight refusal, an injected client resolving no Langfuse client, a start whose run id meets a retained run drawing a fresh id, the Makefile passing task text verbatim; and the trace — the final diff equal to `gdiff -s`, the key pair read from `secrets/langfuse.env`, only a traced Claude role-run switching its plugin on with private settings removed on every way out, one work item whose phases open once and whose rounds keep counting across guidance, stops and answers where they belong, the Codex upload, the trace link, and the trace contract's names, levels, error types, scores, tags, environment, release, masking and dashboard |
| `test_trace_parity.py` | the Temporal run writes, row by row, the rows kept for the same scenario in `fixtures/trace_rows.json`; repository and target from the run; no trace write ever retried; replaying a run writes no row — control: `TelemetryInWorkflow` writes one again |
| `test_replay.py` | the recorded histories in `histories/` replay on the workflow — control: `ChangedRun`, one unpatched change, fails |
| `test_launch.py` | a user systemd manager that hangs neither hangs a refused launch nor keeps a tree alive after its owner's death — control: the hanging shims do hang; a role-run's whole process tree ending on a timeout, a Stop, the agent's exit and its owner's death, on both hosts — every case run twice, the second time against a descendant that starts a session of its own to escape; the owner killed at moments spread across the launch itself — control: an uncontained launch leaves survivors; on Windows the owner killed after creating the agent and before it could be placed in a job leaving nothing — the agent is born inside its job; on POSIX a launch with no reachable systemd user manager refused before the agent runs — control: the same agent runs when it is reachable; task text reaching argv and stdin byte for byte — control: a shell executes it |
| `test_worktrees.py` | against real repositories: a run id that reads as its task and is a valid branch, folder and short enough for a Windows path; a stale branch of the run's name refused while one still at the base is adopted; a Windows worktree past the path limit refused before it exists — control: one character shorter fits; a worktree created in its root and adopted when made again; LFS files kept as pointers; the controller-only guard; an agent's git unable to reach a remote, and a push it actually attempts — including through `-c protocol.allow=always` — reaching none, control: the same push outside that environment lands; the worktree view; the approved merge, its plan moved or — for a repository without a done folder — deleted, and cleanup; a conflict handed back and merged after its resolution; a merge whose commit was refused after the plan was finished merging when continued, with or without a done folder and with the plan's line endings kept, and one refused after its work commit was written merging when continued; a merge already written adopted rather than repeated, while another run's merge carrying the same message is not; cleanup refusing an unmerged branch and removing nothing; discard; and every deletion guard on a worktree's environment |
| `test_terminal.py` | a role turn in a live terminal, through the real PTY host, hooks and contained tree against `fake_cli.py` on both hosts: it ends on its own turn's completion only — a prompt of another session, an earlier prompt, a `Stop` while a background task runs or Codex's title turn never end it, while the completion of a redirect the operator typed after Esc does, and a resumed Codex thread's cumulative inputs match, control: events a first-event rule would accept; a multi-line prompt reaching the agent whole; the Codex thread taken from its turn and resumed by; `StopFailure`, an exit without completion and a timeout failing the step and ending the agent; the next turn replacing the agent and appending to the record; Esc and typing reaching the agent while an interrupt completes nothing; the run's close and the worker's death ending the agent and a detached descendant — control: a descendant outside the terminal survives; the WebSocket refusing another origin, a missing token and an unknown role, sending a live terminal's record then its bytes and taking keystrokes, and replaying a closed one read-only; a Claude hook payload read as UTF-8 whatever the locale; a lost session showing each CLI's measured message for rehydration; a change to the worktree during the architect's verify turn failing the step, control: an untouched worktree verifies; closing a run closing its viewers' connections; the merge and the discard ending the run's agents before git runs, and a step failed by its checks ending its agent; an agent never inheriting a parent Claude Code session |
| `test_workbench.py` | the workbench's API over real runs on the time-skipping server: the token, another origin and a rebound host name refused; the page carrying its config and forbidding framing; a run started, listed, reviewed with its change read on its host, answered — an answer its stop does not offer refused by the workflow, one for a stop it has left refused — and merged |
| `test_trust.py` | what a run records so its agents meet no trust dialog: the key each CLI on this host reads, the operator's own file kept whole (Claude's replaced atomically with its contents plus the entry, Codex's only appended to), nothing recorded twice however the path is spelled, a file we do not understand left alone, and a record that cannot be written costing a dialog rather than the run; the `prepare` activity records the run's repository for the brains it will use. That a record silences the real dialog is measured against the installed CLIs in acceptance, not here |
| `test_architecture.py` | the rules this repository keeps about its own source: the four layers its imports already follow, with nothing importing an entry point; that no unit test writes a trust record into the operator's real home — the one incident this suite has caused; and that a turn refuses an agent the host cannot wire, leaving nothing behind. Every check carries a control that proves it can reject a violation |
| `test_repos.py` | the repository descriptor over detection: base branch, worktree root, todo convention, flags; only the done folder may be null; every refusal; a Windows target on a Linux path refused — control: a Windows process given one runs in `C:\Windows` |
| `fakes.py`, `temporal_env.py` | the fake seams, and one test server with its workers per test process |
| `fake_cli.py` | a stand-in for the interactive `claude` and `codex` CLIs: their completion hooks, Esc, typing and a detached descendant |
| `empty_workflow.py`, `control_workflows.py`, `control_trace_sink.py` | the controls: workflows that each lack one guarantee |
| `trace_rows.py` | a trace reduced to what the contract promises, for the row-by-row comparison |
| `record_histories.py` | records `histories/` — rerun only for a deliberate change to the workflow, behind `workflow.patched` |
| `acceptance_restart.py` | acceptance on the live stack with fake agents on a throwaway repository: a restart while a run waits, a worker killed mid-role, run ids refused while open and after closing, a merge and a discard; that the run's own `prepare` recorded its repository for the CLIs it uses; that a plan changed at the approval stop is assessed again with no build turn run; and that the final gate's change — deliberately larger than one payload — comes in parts that all name one change and join byte for byte into the patch an independent `git` run prints. It forgets the trust records it made and leaves nothing on the host |

Real Claude and Codex on real repositories are exercised by real runs, not by this suite.
