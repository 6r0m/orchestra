# Done

Completed task records. A merged engineering increment whose task remains unfinished stays active,
parked or in backlog under the [todo lifecycle](../README.md); merging alone does not put it here.
Explicit operator closure can complete a defined task scope before a commit.

A repository may say it deletes a finished plan instead, by setting `todo_done_dir` to `null` in
its `repos.json` entry. This repository keeps them.
